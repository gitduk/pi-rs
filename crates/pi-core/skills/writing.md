# Writing for a model

A model reads descriptions and instructions without a person to explain them.
Write each sentence so that it has only one meaning.

## Rules

- Use the active voice. Name the actor: "pi skips the skill", not "the skill is skipped".
- Write one instruction in each sentence.
- Keep instructions to 20 words or fewer, and descriptions to 25 words or fewer.
- Use a numbered list for three or more steps, and a bulleted list for three or more conditions.
- Give each concept one name, and use that name every time.
- Use a verb for an action: "check the file", not "perform a check of the file".
- Use one-word verbs instead of phrasal verbs: "start", not "spin up".
- Do not use semicolons. Write two sentences.
- Do not drop the subject, the verb, or the article to save words.
- Do not stack more than three nouns in one phrase.

## Content

- State the claim. Remove qualifiers that add no information, such as "it is important to note that".
- Keep a hedge that carries real uncertainty, such as "may have failed".
- Replace words that claim quality, such as "robust" or "seamless", with the fact that supports the claim, or remove them.
- Keep every condition, exception, limit, and number, even when the sentence becomes longer.
- Do not add a cause, a frequency, or a guarantee that you did not verify.
- Stop shortening a sentence when it has one meaning. A shorter sentence is not the goal.
